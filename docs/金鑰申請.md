# 金鑰申請與設定教學（tw-line-faq-bot）

| 項目 | 必填？ | 去哪裡拿 | 費用 | 填在 `.env` |
|---|---|---|---|---|
| LINE Channel secret | ✅ 必填 | LINE Developers Console | 免費 | `LINE_CHANNEL_SECRET` |
| LINE Channel access token | ✅ 必填 | LINE Developers Console | 免費（訊息則數依官方帳號方案） | `LINE_CHANNEL_ACCESS_TOKEN` |
| 老闆認證碼 | ✅ 必填其一 | **自己想一組** | 免費 | `BOT_OWNER_CLAIM_CODE` |
| 老闆的 LINE userId | 選填（可取代認證碼） | LINE Developers Console | 免費 | `BOT_OWNER_USER_ID` |
| Anthropic（Claude）API 金鑰 | 選填 | Claude Console | 依用量計費 | `ANTHROPIC_API_KEY` |

---

## 先做一次：建立 `.env` 檔

1. 在專案資料夾把 **`.env.example`** 複製一份，檔名改成 **`.env`**（Windows 看不到副檔名：檔案總管 →「檢視」→ 勾「副檔名」）。
2. 用記事本打開，把下面拿到的值貼在等號後面，**不要加引號、不要有空格**，存檔。
3. 重新啟動 bot（`停止.vbs` → `背景啟動.vbs`）。

> 🔒 `.env` 不會被 git 上傳。**Channel access token 等於整個官方帳號的控制權**（可以用你的帳號對所有好友發訊息），不要貼到聊天室、不要截圖。

---

## 一、LINE 官方帳號與 Messaging API（必填）

### 1. 建立 LINE 官方帳號

1. 打開 [LINE Official Account Manager](https://manager.line.biz/)，用你的 LINE 帳號登入。
2. 按「建立 LINE 官方帳號」，填帳號名稱（例如店名）、業種、Email，送出。
3. 建好後會進到官方帳號的管理後台。

### 2. 開啟 Messaging API

1. 在官方帳號管理後台，右上角「設定」→ 左側「**Messaging API**」→「啟用 Messaging API」。
2. 第一次會要你選或建立一個 **Provider**（開發者名稱，例如公司名或自己的名字）。
3. 完成後這個官方帳號就會出現在 [LINE Developers Console](https://developers.line.biz/console/) 的那個 Provider 底下，類型是 Messaging API channel。

### 3. 拿到 Channel secret

1. 打開 [LINE Developers Console](https://developers.line.biz/console/) → 點你的 Provider → 點這個 channel。
2. 「**Basic settings**」分頁往下找「**Channel secret**」→ 複製。

```
LINE_CHANNEL_SECRET=（貼上）
```

用途：確認 webhook 收到的訊息真的是 LINE 送來的（驗證簽章）。

### 4. 拿到 Channel access token（長效）

1. 同一個 channel，切到「**Messaging API**」分頁。
2. 拉到最下面「**Channel access token (long-lived)**」→ 按「**Issue**」→ 複製。

```
LINE_CHANNEL_ACCESS_TOKEN=（貼上）
```

用途：bot 用它回覆客人、推卡片給老闆。

### 5. 老闆身分（二選一）

**做法 A（推薦）：認證碼**

自己想一組不容易被猜到的字（**至少 6 個字**，建議 8 位以上英數混合；太短 bot 會拒絕啟動）。同一人 15 分鐘內輸錯 5 次會暫時被鎖住：

```
BOT_OWNER_CLAIM_CODE=（自己想的認證碼）
```

bot 跑起來後，老闆用自己的 LINE 對官方帳號傳「`我是老闆 認證碼`」就綁定了。可以綁好幾位（老闆、店長）。認證碼不要公開；有人離職就改一組新的。

**做法 B：直接填 userId**

在 LINE Developers Console → 這個 channel →「Basic settings」最下面的「**Your user ID**」是**你自己**的 userId（U 開頭、33 個字元）：

```
BOT_OWNER_USER_ID=U（貼上）
```

### 6. 費用說明

- 建立官方帳號、Messaging API、token 都免費。
- **回覆（reply）客人的訊息不計費**（老闆傳「待辦」補看卡片也走 reply，額度用完還是看得到）；bot 推卡片給老闆、逾時改用推播（push）的訊息，會算進官方帳號方案的每月訊息則數。
- 免費方案每月有固定則數上限，超過要升級方案。實際則數與價格**以 LINE 官方帳號方案公告為準**。一般小店老闆每天收幾張決策卡，免費額度通常夠用。

### 7. 外流了怎麼辦

- token 外流：回到「Messaging API」分頁，重新 Issue 一把新的（舊的會失效），更新 `.env` 後重啟。
- channel secret 外流：「Basic settings」→ Channel secret 旁邊按「Issue」重新產生。

## 二、Anthropic（Claude）API 金鑰（選填：AI 補答）

不填的話，FAQ 答不出來的問題會直接推給老闆，**完全不會呼叫 AI、不花錢**。

1. 打開 [Claude Console](https://console.anthropic.com/) 註冊登入，建立組織。
2. 「Settings」→「Billing」綁卡儲值；建議到「Settings」→「Limits」設每月花費上限。
3. 「Settings」→「API Keys」→「Create Key」→ 複製 `sk-ant-` 開頭的金鑰（**只顯示一次**）。

```
ANTHROPIC_API_KEY=sk-ant-（貼上）
BOT_AI_MODEL=claude-sonnet-5-5
# 選填：用量控管（預設值如下）。每位客人每小時、全店每 24 小時最多呼叫 Claude 幾次，超過就直接推給老闆
BOT_AI_PER_USER_HOUR=6
BOT_AI_DAILY_CAP=300
```

重啟後打開 http://localhost:18800/health ，看到 `"ai": true` 就是讀到了。

費用：依實際用量（token）計費。知識庫內容用 prompt caching 重複使用，重複的部分不會每次算全價。AI 被要求「知識庫沒寫的不答」，沒把握就推給老闆。金鑰外流時到 Console 刪掉那把再建新的。

## 三、讓 LINE 連得到你的電腦（不用金鑰）

LINE 要能從網路呼叫你的 bot，最簡單是 [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) 臨時通道（免費、免註冊）：

```bash
cloudflared tunnel --url http://localhost:18800
```

把印出的 `https://xxxx.trycloudflare.com` 加上 `/callback` 填到 LINE Developers Console →「Messaging API」→「Webhook URL」，按「Verify」，並打開「Use webhook」。臨時通道每次重開網址會變；長期使用請改用 cloudflared 具名通道（要 Cloudflare 帳號與網域）或自己的主機。
